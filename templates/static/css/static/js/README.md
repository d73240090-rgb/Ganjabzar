# گنج ابزار 🛠️

سیستم اجاره ابزار در البرز و تهران

## ویژگی‌ها
- ثبت آگهی رایگان ابزار
- جستجو بر اساس منطقه
- نمایش لیست ابزارها

## تکنولوژی‌ها
- Backend: Python Flask
- Frontend: HTML, CSS, JavaScript
- Database: SQLite
- Hosting: Liara

## نصب و راه‌اندازی

1. کلون کردن پروژه:
```bash
git clone https://github.com/yourusername/ganj-abzar.git
```

2. نصب پیش‌نیازها:
```bash
pip install -r requirements.txt
```

3. اجرای برنامه:
```bash
python app.py
```
